## 工作规则

- 每个工作包形成一个可审查逻辑提交；先在 `codex/milestone-11-*` 任务分支验证，再合并到 `main`，最后统一推送。
- 配置解析只接受项目受控预设目录与字段白名单；先验证完整候选快照，再原子替换当前有效快照。
- 不修改 `Protocol.md`、Python/UE 协议 Schema、Tool 枚举或 Provider 行为；发现协议缺口时记录原因，不在本里程碑绕过协议。
- 蓝图、地图、动画、蒙太奇、材质和其他二进制资源由用户配置；代码交付必须在这些资源未配置时安全回退。
- Task 状态变化时同步 [ProjectState.md](./ProjectState.md)；实际命令、数量、环境和结果只写入 Validation 文档。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| `待开始` | 范围和前置条件明确，尚未实施 |
| `进行中` | 已开始实施；同一任务只有一个主要执行者 |
| `受阻` | 无法继续，已记录原因和解除条件 |
| `待验收` | 实施完成，正在执行规定验证 |
| `已完成` | 产物、适用验证和文档均已完成 |
