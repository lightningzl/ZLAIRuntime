## 状态定义

| 状态 | 含义 |
| --- | --- |
| `待开始` | 范围和前置条件明确，尚未实施 |
| `进行中` | 已开始实施；同一任务只有一个主要执行者 |
| `受阻` | 无法继续，已记录原因和解除条件 |
| `待验收` | 实施完成，正在执行规定验证 |
| `已完成` | 产物、适用验证和文档均已完成 |
